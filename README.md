# Burizza — play build

**Play:** https://markcling07.github.io/burizza-play/

Burizza is a turn-based champion battler (Season 1: Ashfall Road). Pick a champion,
recruit two allies, and fight your way down Ashfall Road. Works on phones (portrait)
and desktop browsers. Your progress is saved in your own browser.

This repository only holds the playable files; it is published from the main project.
